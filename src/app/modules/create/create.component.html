How to Use Burn It

(press ESC or click here to close this dialog)

Type in any messages, and press Ctrl + S to save.

By default, the message can only be opened once and expires in 1 week, then it will be removed from the server. However, you can also add specific configurations to the message by typing the configuration, follow by --- and your message. For example:

nocopy
password secret sauce
expires 1d
delete 1 view
---
This message requires the password "secret sauce" to open, and will be destroyed after 1 day or 1 view.

Available Configuration: (click here for the full list)

• alias followed by the custom name you want for your URL.

• nocopy will attempt to make the message uncopiable from the browser.

• password followed by the password you want to protect your secret.

• expires followed by the condition which after being met, the message will be destroyed.

• Valid condition units are: views, minutes, hours, days, weeks, months, years.

• Set the view to 0 to allow unlimited views.

• If you configure the expiration by date, or by views, the other default configuration will still remain active (e.g. if you configure expires 10 days, the message still have the property of expires 1 view). You need to overwrite that to get the desire effect.

• If a message starts with --- without any configuration lines above it, --- will be considered part of the message itself and the message will be saved with no configurations.

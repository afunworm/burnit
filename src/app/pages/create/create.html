How to Use Burn It

(press ESC or click here to close this dialog)

Type in any message, and press Ctrl + S to save.

By default, the message can only be opened once and expires in 1 week, then it will be removed from the server. Messages are encrypted in your browser, and the key is only part of the link you share, so the server never sees your message.

You can also add configurations to the message by typing them, one per line, followed by --- and your message. For example:

nocopy password secret sauce expires 1d delete 1 view --- This message requires the password "secret sauce" to open, and will be destroyed after 1 day or 1 view.

Available Configuration: (click here for the full list)

• alias followed by the custom name you want for your URL.

• nocopy will attempt to make the message uncopiable from the browser.

• password followed by the password you want to protect your secret.

• expires followed by the condition which after being met, the message will be destroyed.

• Valid condition units are: views, minutes, hours, days, weeks, months, years.

• Set the view to 0 to allow unlimited views. Messages always expire within 1 year.

• Configuring only the time or only the views keeps the default for the other (e.g. expires 10 days still has the property of expires 1 view).

• Configuration is only recognized when the first line starts with a configuration keyword. Otherwise, the whole text (including ---) is saved as the message.

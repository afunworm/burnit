NAME

burnit - share a secret that destroys itself after reading

SYNOPSIS

[config lines] --- your secret message

Without config, a message burns after 1 view or 1 week. It is encrypted in your browser; the key is only in the link (after #), so the server never sees it.

OPTIONS

expires <n> <unit>
Destroy after a number of views or an amount of time. Aliases: exp, delete, destroy, remove.
password <text>
Require a password to decrypt. Aliases: pw, pwd.
alias <name>
Custom link name, 3 - 20 letters or numbers. Alias: name.
nocopy
Make the message harder to copy. Aliases: obfuscate.

UNITS

view(s) · m(inutes) · h(ours) · d(ays) · w(eeks) · M(onths) · y(ears)
e.g. expires 3d, expires 2 views. 0 views = unlimited. Messages always expire within 1 year.

EXAMPLE

nocopy password secret sauce expires 1d expires 2 views --- Destroyed after 1 day or 2 views, whichever comes first.
